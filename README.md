# Student Skills Survey
A responsive student skills and career survey built with HTML and CSS.

## Features
- Collects basic student information
- Allows students to slect their skills and interests
- Includes questions about technology confidence
- Includes career-related questions
- Responsive form layout

## Technologies Used
- HTML
- CSS
